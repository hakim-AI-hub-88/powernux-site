Requirements

  • Linux with GNOME 45 to 50 — Ubuntu 24.04+, Debian 13+, Fedora 40+, Linux Mint, Pop!_OS, Zorin, openSUSE…
  • Processor: Intel / AMD (x86-64) or ARM64.
  • Wayland or X11 — Powernux is designed for GNOME on Wayland.

Windows and macOS are not supported: the tools are built on GNOME Shell and Wayland.

Choose your system. Every command installs the latest version directly from GitHub Releases.

Install tools


Powernux contains no tools: you install only the ones you need. In Tools Manager, click Download on a tool. Powernux then:


  1. downloads it from GitHub Releases (the right version for your processor),
  2. verifies its SHA-256 checksum and Ed25519 signature,
  3. installs it and turns it ON.


Click a tool to open its page: ON/OFF switch, settings (shortcut, provider, keys…), actions and Remove. When a new version is published, an Update button appears.


Log out and back in once after installing Smart Window Manager, Voice Typing, Focus Mode or AI Face. On Wayland, GNOME loads new Shell extensions only at login.

AI providers & keys


Voice Typing works with Groq (fast, free tier), OpenAI, AssemblyAI, or any OpenAI-compatible server. AI Face Assistant works with Groq, OpenAI, Google Gemini, Mistral, OpenRouter, or Ollama locally (no key, nothing leaves your PC).


  1. Create a key on the provider's website (e.g. console.groq.com).
  2. Open the tool's page in Powernux and paste it in the key field.
  3. The key is stored encrypted in the GNOME Keyring — never in plain text, never shared.


The Advanced developer mode button on a tool page unlocks custom providers: API address, model, key and authentication header.



Background & startup


Tools you turn on start automatically when you log in — without opening Powernux. A small launcher (powernux --autostart) starts them and exits in about half a second. You can turn this off in Settings → Startup. Closing the Powernux window never stops your tools.

Create a tool


A tool is an independent program plus a manifest.json. Powernux builds its settings page automatically from it.


{
  "id": "my-tool",
  "name": "My Tool",
  "version": "1.0.0",
  "entry": "my-tool-binary",
  "settings": [
    { "key": "shortcut", "type": "shortcut", "label": "Shortcut", "default": "<Super><Shift>m" }
  ],
  "shortcuts": [{ "setting": "shortcut", "name": "My Tool", "args": ["--show"] }]
}


  • Setting types: toggle, select, shortcut, text, secret (stored in the keyring).
    • 

  • Your program receives --reload when a setting changes and --quit when it is turned off.
    • 

  • Write status.json (level, message) to show a message in Tools Manager.

Troubleshooting


“Log out and back in once” stays orange


GNOME has not loaded the tool's extension yet. Log out completely (not just lock the screen) and log back in. Check that extensions are enabled in the Extensions app.


A shortcut does nothing


Open the tool's page: the status message explains what is missing (key, re-login…). Make sure the tool is ON and the shortcut is not used by another app.


“Catalog unavailable”


Powernux could not reach GitHub. Check your connection, then click Refresh in Tools Manager. Installed tools keep working offline.


Voice Typing: “Invalid API key”


Paste a new key in the tool's settings — it replaces the one stored in the keyring.


Still stuck? Open an issue on GitHub.
